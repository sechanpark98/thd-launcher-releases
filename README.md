# The Hundredth Dawn Launcher — downloads

Installers for the **The Hundredth Dawn** launcher (Windows and macOS). The launcher signs you in with Microsoft,
installs Java, Minecraft 1.20.1, Forge and the THD modpack, keeps them up to date, and starts the game.

**Get the latest version:** [Releases → Latest](../../releases/latest)

| Computer | File |
|---|---|
| Windows 10 / 11 (64-bit) | `THD-Launcher-win-x64.exe` |
| macOS, Apple silicon (M1–M4) | `THD-Launcher-mac-arm64.dmg` |
| macOS, Intel | `THD-Launcher-mac-x64.dmg` |

The installers are not code-signed, so the first launch shows a warning:
- **Windows:** in the SmartScreen window press **More info → Run anyway**.
- **macOS:** open **System Settings → Privacy & Security** and press **Open Anyway** near the bottom.

Your Microsoft password is only ever typed on Microsoft's own page; the launcher keeps its sign-in token on your
computer, encrypted by the operating system.

Website: https://thehundredthdawn.duckdns.org/ · Discord: https://discord.gg/cKg83Es83E
